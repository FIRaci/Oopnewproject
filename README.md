# XiNoClone (XiNoClo)

XiNoClone is an AI-powered, feature-rich desktop application built with Java Swing. It serves as a comprehensive workspace combining advanced note-taking, task management, screen text extraction (OCR), and local AI integrations.

## 🚀 Key Features

*   **📝 Advanced Note Management**: Create, edit, and organize your notes seamlessly. Features include rich text editing, categorization via folders, and tagging.
*   **🤖 Local AI Integration (Ollama)**: Leverages local AI models (`gemma3:1b`/`gemma3:4b` via Ollama) to provide intelligent features without compromising privacy:
    *   **Auto-Summarization**: Summarize lengthy notes concisely.
    *   **Smart Translation**: Translate selected text instantly.
    *   **Auto-Tagging**: Generate relevant tags based on note contents automatically.
*   **🔍 Screen OCR Scanner**: Built-in screen snipping and Optical Character Recognition (powered by `tess4j`). Select any area on your screen to extract text directly into your notes.
*   **⏰ Alarms & Missions**: Manage your tasks and "missions" effectively with a built-in reminder and alarm system.
*   **🎨 Modern UI/UX**: Features a sleek, modern interface utilizing `FlatLaf` with support for dynamic theming (Dark/Light modes).
*   **✏️ Drawing Mode**: Integrated drawing canvas for quick sketches and handwritten ideas.

## 🛠️ Technology Stack

*   **Language**: Java 11+
*   **GUI Framework**: Java Swing with [FlatLaf](https://www.formdev.com/flatlaf/)
*   **AI Engine**: Local LLMs via [Ollama](https://ollama.com/)
*   **OCR**: [Tess4J](http://tess4j.sourceforge.net/) (Tesseract OCR API)
*   **Build Tool**: Maven
